## Module 4: Image Processing via Machine Learning
Unlike the previous modules, image processing tends to be much heavier compute-wise. We usually have much larger datasets (10s of GBs) and our libraries take a lot longer to install/run. For those reasons, I recommend to complete this module locally, in your own PC.

1. Get started with Anaconda: https://www.anaconda.com/download
2. Download the dataset here: https://drive.google.com/file/d/1Y1G1WwkHfg-g-i-Ddgv5jQsJqKjuqF86/view?usp=share_link
3. Create a folder in your computer and put the unzipped dataset + jupyter notebook in it
4. Follow the step-by-step in the jupyter notebook and run each cell individually
5. If you use our code in any capacity, please cite our work: Zhang, X., Ding, R., Ferreira, R., Zaluzec, N., and Chen, J. "Direct Observation Reveals That Pt Micelle Disassembly Proceeds through Metastable Pt-PVP-Pt Dumbbells, Enabled by a Droplet-Reactor LP-TEM Platform." _Manuscript in preparation._
