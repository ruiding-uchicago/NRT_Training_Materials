Module 1c - Dataset Gallery: one pipeline, five domains¶

Module 1a built a composition-to-property pipeline on OER electrocatalysts: map each element to physical properties, climb a model ladder from linear to committee, then read the result with SHAP. This notebook runs that same pipeline across five small datasets from different fields, so you can point it at the domain closest to your own research and see how the pipeline behaves there.

Everything 1a teaches still holds, so we do not re-explain it. The point here is coverage: pick a dataset, run, compare. All five load through matminer, which needs no API key.

For each dataset we use the same composition features as 1a plus whatever descriptor columns the dataset provides.

2. Load and cache¶

load_one reads a cached CSV if present, otherwise fetches through matminer and writes the cache. Each CSV holds the composition, the target, and the dataset's descriptor columns. After the first run the notebook is offline and fast, one file per dataset under data/gallery/.

In [5]:
MAX_CARD = 20     # keep a categorical column only if it has at most this many distinct values
MAX_MISS = 0.30   # drop a column missing in more than this fraction of rows

def load_one(name):
    """Return the dataset's full usable dataframe (composition + descriptor columns + target),
    cached under data/gallery/. Descriptors are every field the dataset ships except the target,
    the composition/formula string, database ids, mostly-missing columns, the high-cardinality
    text columns, and the columns listed in 'drop'."""
    cfg = DATASETS[name]
    cache = f"data/gallery/{name}.csv"
    if os.path.exists(cache):
        return pd.read_csv(cache)
    raw = load_dataset(name).dropna(subset=[cfg["comp"], cfg["target"]]).reset_index(drop=True)
    skip = set(cfg["drop"]) | {cfg["comp"], cfg["target"]}
    keep = {}
    for c in raw.columns:
        if c in skip or c.lower().endswith("id"):        # target, composition, or a database id
            continue
        s = raw[c]
        if s.isna().mean() > MAX_MISS:                    # too sparse to be useful
            continue
        if pd.api.types.is_numeric_dtype(s) or s.nunique() <= MAX_CARD:
            keep[c] = s                                   # numeric, or low-cardinality categorical
        # high-cardinality text (formulas already dropped, symbols, ids) is skipped
    d = pd.DataFrame({"composition": raw[cfg["comp"]], **keep})
    d["target"] = raw[cfg["target"]].astype(float)
    d.to_csv(cache, index=False)
    return d

3. Featurize: composition backbone plus the dataset's descriptors¶

The backbone is 1a's idea at larger scale: matminer's ElementProperty "magpie" preset turns each composition into 132 statistics (mean, spread, range, and mode of tabulated atomic properties such as atomic number, electronegativity, and number of valence electrons). These are the transferable part, they exist for any composition in any dataset.

On top of the backbone we add the descriptor columns load_one kept. Numeric descriptors go in as is; low-cardinality categoricals (Heusler struct type, the perovskite site elements) are one-hot encoded. The few remaining gaps are median-imputed. matbench_steels and expt_formation_enthalpy ship no usable extra descriptors, so for them the feature matrix is composition only, exactly as in 1a; the others gain their own physics.

In [6]:
EP = ElementProperty.from_preset("magpie")
EP.set_n_jobs(1)             # single process keeps behavior identical on Colab and locally
N_MAGPIE = len(EP.feature_labels())   # 132 composition features

def featurize(df):
    """magpie composition features + the dataset's own descriptor columns -> (X, y).
    df has columns: composition, target, and any descriptor columns load_one kept."""
    comps = [Composition(s) for s in df["composition"]]
    Xmag = pd.DataFrame(EP.featurize_many(comps, ignore_errors=True, pbar=False),
                        columns=EP.feature_labels())
    extra = {}
    for c in df.columns:
        if c in ("composition", "target"):
            continue
        s = df[c]
        if pd.api.types.is_numeric_dtype(s):
            extra[c] = s.astype(float).to_numpy()
        else:                                             # low-cardinality categorical -> one-hot
            for col, vals in pd.get_dummies(s, prefix=c).items():
                extra[col] = vals.astype(float).to_numpy()
    X = pd.concat([Xmag, pd.DataFrame(extra, index=Xmag.index)], axis=1)
    y = df["target"].astype(float)
    keep = Xmag.notna().all(axis=1)                       # drop compositions the featurizer could not parse
    X, y = X[keep].reset_index(drop=True), y[keep].reset_index(drop=True)
    X = X.fillna(X.median(numeric_only=True))             # impute the few remaining descriptor gaps
    return X, y

4. The model ladder (same as 1a)¶

Linear, decision tree, random forest, XGBoost, MLP, then a committee that averages the last three and reports their spread as an uncertainty signal. The code is 1a's; only the data changed. We print the compact scoreboard for the close-up dataset.

In [7]:
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeRegressor
from sklearn.ensemble import RandomForestRegressor
from sklearn.neural_network import MLPRegressor
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from xgboost import XGBRegressor

def build_models():
    return {
        "Linear":       LinearRegression(),
        "DecisionTree": DecisionTreeRegressor(max_depth=8, random_state=RND),
        "RandomForest": RandomForestRegressor(n_estimators=300, n_jobs=-1, random_state=RND),
        "XGBoost":      XGBRegressor(n_estimators=400, learning_rate=0.05, max_depth=5,
                                     subsample=0.8, colsample_bytree=0.8, random_state=RND, n_jobs=-1),
        "MLP":          make_pipeline(StandardScaler(),
                            MLPRegressor(hidden_layer_sizes=(256, 128), alpha=3e-4,
                                         learning_rate_init=8e-4, max_iter=1500, early_stopping=True,
                                         n_iter_no_change=30, random_state=RND)),
    }

def run_ladder(X, y, seed=RND):
    Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.1, random_state=seed)
    res = {}
    for name, m in build_models().items():
        m.fit(Xtr, ytr); p = m.predict(Xte)
        res[name] = dict(model=m, pred=p, R2=r2_score(yte, p), MAE=mean_absolute_error(yte, p))
    P = np.column_stack([res[k]["pred"] for k in ["RandomForest", "XGBoost", "MLP"]])
    ens, std = P.mean(1), P.std(1)
    res["Committee"] = dict(model=None, pred=ens, R2=r2_score(yte, ens),
                            MAE=mean_absolute_error(yte, ens), std=std)
    return dict(res=res, split=(Xtr, Xte, ytr, yte))

fit = run_ladder(X, y)
u = DATASETS[DATASET]["unit"]
for name, r in fit["res"].items():

5. The gallery: best model on every dataset¶

The same ladder on all five domains, reduced to one row each: the feature count (magpie plus descriptors), the best model, its test R2, and MAE in the target's own unit. Read down the R2 column and the pattern from 1a repeats: tree ensembles (or, on the larger sets, the MLP) lead, and the linear baseline trails.

Heusler shows why the descriptor columns matter. Its magnetic moment follows the Slater-Pauling rule (it scales with valence electron count) and depends on the Heusler structure type, and the dataset provides both as num_electron and struct type, so the best model reaches about 0.85.

rows = []
for name in DATASETS:
    Xi, yi = featurize(load_one(name))
    r = run_ladder(Xi, yi)["res"]
    reg = {k: v for k, v in r.items() if k != "Committee"}

    rows.append(dict(dataset=name, domain=DATASETS[name]["label"], n=len(yi),
                     n_feat=Xi.shape[1], n_descr=Xi.shape[1] - N_MAGPIE,

7. Same features, a classification task¶

Regression predicts a number; sometimes the useful question is a class. Without a new dataset, we split the same target at its median into high vs low and train a classifier on the same features. Here that reads as "will this composition land in the top or bottom half of the target?" We report accuracy and F1 on the held-out test set.

8. Find your domain¶

The five datasets span alloys, ceramics, photovoltaics, magnetics, and thermodynamics. Pick the one closest to your own materials, set DATASET to its key, and run top to bottom. To go further to your own table, replace load_one with a pd.read_csv of your data: keep a column named composition (a formula or a composition string) and a numeric target, and add any numeric or low-cardinality categorical descriptor columns you have, since featurize folds every non-composition, non-target column into the feature matrix automatically. From there, featurization through SHAP runs unchanged. That is the same portability 1a promised, now shown across five domains.
